# 多平台账号数据采集与桌宠助手

基于 Python 的个人账号数据采集工具：以透明置顶的桌宠作为主程序，支持 X、小红书、pixiv 三个平台的本人账号数据采集，长期累积到本地 CSV，并生成「KPI + 热力图 + 分析曲线」的可视化报告。双击桌宠打开观测台，查看数据与触发采集；观测台内置本周分时段任务表，到点由桌宠弹出提醒。

- 无数据库，数据按平台存储在 `data/platforms/` 下
- 界面使用 tkinter，仅需 `requests`；浏览器登录可选 `playwright`
- 只采集本人账号、低频串行请求；不实现登录伪装或验证码绕过

## 功能

- 桌宠主程序：透明置顶 GIF 角色、拖拽记忆位置、气泡播报、右键菜单
- 桌宠外观：内置小猪、阿米娅、跳舞小猫三套动画外观，右键即时切换并记忆
- 内置音乐：每个外观绑定一首曲目，右键播放 / 暂停 / 切歌；支持从外部导入、删除曲目并直接显示音乐文件名
- 数据管理：设置页可清除当前平台的采集数据，避免错误数据污染分析
- 本周计划：7 天 × 6 个固定时段，同一时段可放多个带标题与自定义时间的任务，桌宠开始前与到点各提醒一次
- 文件检索：多个目录按顺序扫描，支持名称、后缀与文件类型筛选，后台检索可停止
- 三平台采集：X、小红书、pixiv 适配器独立模块、配置驱动、动态加载与卸载
- 平台数据隔离：每平台独立目录与指标列，平台不提供的指标不写入
- 采集稳定性：超时、重试、指数退避、限频、按错误类型冷却
- 浏览器会话桥接：打开独立浏览器由本人手动登录，只读取会话锚点 Cookie（pixiv 为 `PHPSESSID`）
- 采集准确性：统一字段归一化、必填校验、批次去重、快照幂等、账号数据交叉校验
- 监控面板：平台切换、帖子列表、字段覆盖度、本轮互动增量
- 报告：KPI、星期 × 小时热力图、每日/每小时曲线、Top 3 帖子曲线
- CLI：单平台采集、全平台常驻、按平台生成报告

## 配置

编辑 `config.json`，或在桌宠/监控面板点「设置」按平台填写（会写回同一文件）。

### 平台配置

```json
"platforms": {
  "x": {
    "enabled": true,
    "account_name": "your_handle",
    "platform_user_id": "123456",
    "session_id": "粘贴 PHPSESSID / auth_token 等会话锚点值",
    "cookies": "",
    "max_posts": 50,
    "filters": {
      "include_keywords": [],
      "exclude_keywords": [],
      "exclude_reposts": false,
      "exclude_replies": false,
      "only_changed": false
    },
    "retry": {"max_attempts": 4, "backoff_seconds": 2, "backoff_max_seconds": 60},
    "rate_limit": {"min_interval_seconds": 3, "max_requests_per_minute": 20},
    "timeout": 20
  }
}
```

其余平台键为 `xiaohongshu`、`pixiv`。字段说明：

| 字段 | 说明 |
| --- | --- |
| `enabled` | 是否参与调度 |
| `account_name` | 账号名称 / handle |
| `platform_user_id` | 平台用户 ID，仅小红书、pixiv 必填；X 自动解析，设置里不显示该字段 |
| `session_id` | 会话锚点值，只保存这一项；锚点名见下表 |
| `cookies` | 程序自动获取的必需附加 Cookie（如 `ct0`），设置里不提供输入框 |
| `max_posts` | 每轮最多采集条数，默认 50 |
| `filters.include_keywords` | 仅保留标题/正文包含这些词的帖子 |
| `filters.exclude_keywords` | 排除包含这些词的帖子 |
| `filters.exclude_reposts` | 排除转发 |
| `filters.exclude_replies` | 排除回复别人的帖子（回复自己的线程保留） |
| `filters.only_changed` | 只保留相对上次抓取指标有变化的帖子 |
| `note_detail_limit` | 仅小红书：打开笔记详情补齐互动指标的篇数上限（主页卡片只显示点赞数），`0` 表示关闭 | 5 |
| `retry.*` / `rate_limit.*` / `timeout` | 重试、限频与超时 |

各平台的会话锚点与自动获取的附加 Cookie：

| 平台 | 必填用户 ID | 锚点 Cookie | 自动获取 |
| --- | --- | --- | --- |
| X | 否 | `auth_token` | `ct0` |
| 小红书 | 是 | `web_session` | — |
| pixiv | 是 | `PHPSESSID` | — |

设置里只填锚点值；X 的 `ct0` 由「浏览器登录」一并读取，或在首次采集时向站点首页自动获取一次。

锚点值也可用环境变量覆盖：`X_SESSION_X`、`X_SESSION_XIAOHONGSHU`、`X_SESSION_PIXIV`；`X_COOKIE_<平台>` 仍可用于补充附加 Cookie。

设置里的「浏览器登录」会打开独立浏览器窗口（Playwright + 本机 Chrome/Edge），由你手动完成登录（含验证码）后，程序只读取该平台域名下的会话锚点与必需附加 Cookie（如 X 的 `ct0`），其余 Cookie 丢弃；不注入反检测脚本、不换代理、不处理验证码。首次使用需 `pip install playwright`；本机已装 Chrome/Edge 时无需额外下载浏览器。浏览器配置文件保存在 `data/browser/<平台>/`。

## 使用

### 桌宠（默认入口）

双击 `启动.bat`，或执行：

```powershell
pythonw pet.py
```

- 双击桌宠：打开监控面板（已打开时仅提示）；单击：随机吐槽（不同外观有各自的台词）
- 按住左键拖动：移动位置，退出时记住
- 右键菜单：打开观测台、运行监控、本周计划、文件检索、采集全部平台、生成报告、更换外观、播放音乐、音乐子菜单、设置、自动采集、始终置顶、退出
- 采集结果用气泡播报；未配置账号或会话锚点时会提示
- 退出桌宠时会一并关闭由它打开的观测台进程和设置弹窗
- 自检：`python pet.py --selftest`

#### 外观与音乐

右键 →「更换外观」可切换三套内置外观，切换后立即生效并写入 `config.json` 的 `pet.skin`：

| 外观 | 内置曲目 |
| --- | --- |
| 小猪（原版） | 未白镇.mp3 |
| 阿米娅 | 邦友的酒(DJ版).mp3 |
| 跳舞小猫 | 最后的自由.mp3 |

- 右键 →「播放音乐」：播放 / 暂停 / 继续当前外观的曲目
- 右键 →「音乐」：显示音乐文件夹内的完整文件名，支持播放、上一首 / 下一首、停止
- 「导入音乐…」：从电脑其他位置选择一个或多个 mp3 / wav，复制到音乐文件夹；重名文件会跳过
- 「删除当前曲目」：停止播放并删除当前曲目文件
- 「打开音乐文件夹」：可直接在资源管理器中管理音频文件
- 播放器使用 Windows MCI，支持 mp3 / wav；切换外观时，若音乐正在播放会自动切到新外观的曲目；暂停状态下切换则重置为新曲目

### 监控面板

双击桌宠或右键「打开观测台」，也可执行 `pythonw app.py`：左栏为观测台、运行监控、本周计划、文件检索、数据分析、评估报告、设置七个页面；切换平台查看帖子与统计，触发采集或生成报告；「评估报告」页可预览、打开或删除单份历史报告（也可选中后按 Delete）。窗口关闭后桌宠自动恢复定时采集。

设置页为双栏布局（建议窗口不小于 1120×930）：左栏切换平台，右侧依次为平台与账号、会话与凭据、过滤规则、运行策略、数据管理。其中「05 数据管理」会显示当前平台的帖子 / 快照 / 运行记录数量，并可一键清除该平台的采集数据（只删除 `data/platforms/<平台>/` 下的 CSV，不影响配置、登录会话和已生成报告）。

设置、任务编辑、浏览器登录与报告预览等弹窗默认在屏幕中央打开。

### 本周计划

「03 本周计划」按固定时段组织一周安排，每天 6 个时段：

| 时段 | 时间范围 |
| --- | --- |
| 凌晨 | 00:00–06:00 |
| 早晨 | 06:00–09:00 |
| 上午 | 09:00–12:00 |
| 午间 | 12:00–14:00 |
| 下午 | 14:00–18:00 |
| 晚间 | 18:00–24:00 |

- 表格为 7 天 × 6 时段，表头显示本周日期，今天列用朱红标出，当前时段加描边
- 点击任意时段格子打开任务列表：同一时段可添加多个任务，每个任务包含「简要标题」、备注和可选自定义时间
- 简要标题必填，建议 4–12 字；备注可留空；列表下方可直接新增、编辑、删除任务
- 自定义时间可留空并使用时段范围；同一时段内的多个任务可以设置相同或不同时间，但都必须落在时段内且开始早于结束
- 格子最多展示 3 个任务（自定义时间 + 标题），更多任务显示「+N 项」
- 桌宠每分钟检查一次任务表：
  - 开始前 10 分钟提示「任务快到了」
  - 到点时提示「任务到时间了」
  - 同一分钟有多条任务触发时会合并为一条气泡，避免互相覆盖
- 任务按“星期 + 时段”保存到 `data/schedule.json`（v3 多任务格式），每周循环生效；旧版单任务备注会自动迁移
- 右键桌宠 →「本周计划」可直接打开该页面

### 文件检索

「04 文件检索」用于在指定的本机小范围目录中查找文件：

- 左侧可添加多个文件夹，检索严格按列表顺序执行；新添加的范围默认「含子文件夹」
- 直接拖拽列表行即可调整检索优先级，顺序自动保存
- 点击列表最左侧「模式」列可在「仅本级」与「含子文件夹」之间切换；已有范围无需重新添加
- 右键列表项可「切换模式」或「移除」
- 范围与模式保存在 `data/file_scopes.json`，不存在的路径会标红并在检索时跳过
- 筛选条件：
  - 名称包含：文件名子串，不区分大小写
  - 后缀：逗号分隔，如 `pdf, docx, .png`；与文件类型同时填写时取交集
  - 文件类型：全部、文档、图片、音频、视频、压缩包、代码、其他
- 检索在后台线程执行，可随时点「停止」；最多返回 3000 条，同一文件跨范围只保留第一次出现的结果
- 结果表显示文件名、类型、后缀、大小、修改时间与所在路径；双击行可打开文件，也可「打开所在文件夹」或「复制路径」
- 右键桌宠 →「文件检索」可直接打开该页面

### 命令行

```powershell
python main.py platforms                    # 列出平台
python main.py login --platform xiaohongshu # 打开浏览器手动登录并保存会话
python main.py collect --platform x        # 单平台采集
python main.py daemon --interval 30        # 常驻采集全部启用平台
python main.py report --platform x         # 生成报告
python main.py status                      # 各平台本地数据量
```

`login` 会打开一个可见的浏览器窗口停在登录页，由你本人扫码，程序只在检测到真实登录后读取 `web_session` 写回配置；等待超时默认 300 秒（`--timeout` 可调）。

## 打包为 Windows 程序

```powershell
python -m PyInstaller --noconfirm --clean --onedir --windowed --name "猪群友桌宠" --add-data "assets;assets" --collect-submodules xmonitor --collect-data playwright pet.py
```

产物位于 `dist/猪群友桌宠/`：

- `猪群友桌宠.exe`：双击启动桌宠；`--panel` 启动观测台，`--selftest` 运行自检

- 把脱敏后的 `config.json` 放在 exe 同级；运行后 `data/`、`reports/` 也会生成在 exe 同级，便于整包移动
- 打包后静态资源从程序目录读取（`RESOURCE_ROOT`），配置、数据、报告仍以 exe 所在目录为基准

## 分享前脱敏清单

`config.json`、`data/`、`reports/` 都可能包含个人数据，对外分享源码或安装包前请逐项确认：

1. 清空 `config.json` 中所有平台的 `session_id`、`cookies`、`account_name`、`platform_user_id`，并把 `pet.x` / `pet.y` 置空
2. 不要打包或上传 `data/`（含 `data/browser/` 浏览器登录态）、`reports/`、`debug.log`
3. 删除或重新生成 `dist/` 下的旧安装包与压缩包，避免夹带旧配置
4. 检查测试、文档与截图中不含真实账号、用户 ID、会话锚点或采集数据
5. 本项目的 `.gitignore` 已忽略上述运行时文件与本机 `config.json`；对外发布时只保留清空凭据的配置模板

## 数据文件

`data/platforms/<platform>/`：

- `accounts.csv`：账号当前指标
- `posts.csv`：帖子当前值与平台支持的指标列
- `snapshots-YYYY-MM.csv`：30 分钟快照，按月分文件，重复采集覆盖不重复计数

平台不提供的指标不写入列，读取时按缺失处理。所有写入采用「临时文件 + 原子替换」。

## 注意事项

- 网页采集可能违反平台服务条款，请先确认平台规则与当地法规；能申请官方 API 的平台优先用官方 API
- 本项目只采集本人账号，不采集他人数据、不抓取私信或关注列表
- 不实现登录伪装、验证码绕过、指纹伪造、代理轮换；遇到登录墙或 403 会停止并冷却
- `data/`、`reports/`、`*.log`（含 Chrome 生成的 `debug.log`）均为运行时产物，已在 `.gitignore` 中忽略；不要提交浏览器 profile
- `data/browser/<平台>/` 保存浏览器登录态配置，属于敏感数据，请勿分享
- `data/schedule.json` 保存本周任务备注，可能含个人安排，分享或打包前应一并清除
- `data/file_scopes.json` 保存本机检索目录路径，可能暴露个人目录结构，分享前应清除
- `config.json` 含会话锚点与自动获取的附加 Cookie，已在 `.gitignore` 中忽略；分享代码前按上文「分享前脱敏清单」清理
- `assets/` 内的角色帧、源 GIF 与内置音乐仅用于个人演示，版权归各自权利人所有；公开分发前请自行确认授权
- 打包时不要把本机 `data/`、`reports/`、`config.json` 一起放进安装包；安装包只应携带脱敏后的配置模板
- 网页接口结构会变化，解析失败会记录 `ParseError` 并进入冷却，不会静默写入错误数据
- 小红书已对未登录与自动化请求强制跳登录页，且 headless 浏览器会触发风控（`error_code 300012`），因此该平台固定使用**真实 Chromium 渲染通道**：每轮采集启动一个离屏浏览器窗口（持久化 profile 位于 `data/browser/xiaohongshu/`），在页面内解包 Vue state 取数，并按 `note_detail_limit` 打开笔记详情补齐评论/收藏/分享。通道内所有停留均带随机抖动并放慢节奏，以接近真人浏览；HTTP 直连仅作为 playwright 未安装时的兜底
- 小红书只采集主页「笔记」tab 中本人发布的作品，不采集收藏、点赞过的他人笔记
